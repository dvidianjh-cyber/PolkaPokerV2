# Test Report v2.0.0.0

## Automated (Vitest, `npm test`): 22/22 passing
- **Evaluator:** all 10 hand categories, wheel straight, kickers, split ties, board plays.
- **Pots:** side pots for all-ins, uncalled chips returned.
- **Blinds/config:** blinds double every N hands, config validation.
- **Game flow:** heads-up hand to showdown, pause at showdown (no turn, no timer), only next dealer may deal, dealer/SB/BB rotation (heads-up and 3-handed), min-raise and turn validation, timeout = check or fold without unseating, all-in side pots with chip conservation, leaving player folded and removed at next deal.
- **Messages:** malformed/oversized/unknown messages rejected, name sanitisation, action and seat validation, avatar fallback.

## Build
`npm run build` succeeds (about 124 kB JS, 36 kB gzip).

## Manual browser check
- Landing page renders; creating a table connected to the public PeerJS broker and showed code, 8-seat table, blinds info and "Waiting for players" with no console errors.
- **Not yet verified:** a two-browser join/deal/play session and the 320px layout (browser tool was unavailable). Please test these manually.

## Known simplifications
- A short all-in below the minimum raise does not restrict re-raising by players who already acted.
- Busted players are removed at the next deal and may sit again with a fresh buy-in.
- Peers use the public PeerJS broker; no TURN server, so some strict NATs may fail to connect.
